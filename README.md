# مساحة مهامي — Maham Task Manager

تطبيق ويب باللغة العربية لإدارة المهام والمشاريع والتقويم والملاحظات، إضافة إلى تتبّع الدخل والمصروفات والميزانيات والأهداف المالية المستقبلية.

## التشغيل
افتح `index.html` في متصفح حديث، أو انشر الملفات على استضافة ثابتة مثل Hostinger.

## النشر على Hostinger
ارفع ملف `index.html` إلى مجلد `public_html` عبر مدير الملفات، أو اربط المستودع بآلية نشر تدعمها خطة الاستضافة.

## الخصوصية والبيانات
- تستخدم هذه النسخة `localStorage` في متصفح كل جهاز لحفظ المهام والبيانات المالية محلياً.
- لا توجد قاعدة بيانات أو تسجيل دخول أو مزامنة بين الأجهزة في هذه النسخة.
- رفع الشيفرة إلى GitHub **لا يرفع بيانات المتصفح**.
- المستودع عام حالياً؛ لا تضع بيانات مالية فعلية أو مفاتيح سرية ضمن ملفات الشيفرة.
- قبل استخدام الموقع على نطاق متاح للعامة لتخزين بيانات حساسة، يلزم بناء تسجيل دخول وتخزين آمن على الخادم.
- استخدم ميزة تصدير البيانات لعمل نسخة احتياطية دورياً.

## الملف الرئيسي
`index.html` — صفحة التطبيق الكاملة (HTML + CSS + JavaScript).
